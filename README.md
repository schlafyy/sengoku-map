# Sengoku 戦国

An interactive map of Japan's Sengoku period, 1467–1603, as a length of indigo-dyed cotton. Each clan is a dye, and when a province changes hands the new dye soaks across it from the conqueror's side. Press play to watch the whole period in about two minutes, or drag the woven band along the bottom.

## Run it

- **Windows app:** `dist\Sengoku.exe` (one file; uses the Edge WebView2 runtime that ships with Windows 11).
- **In a browser:** serve the folder (`python -m http.server`) and open `index.html`.

## Using it

- **Play** runs 1467→1603 and holds on the turning points (Ōnin, Okehazama, Honnō-ji, Odawara, Sekigahara). Space plays and pauses.
- **The woven band:** each year is a column of 68 threads, one per province, in its holder's dye. Click or drag anywhere on it to jump. With it focused, ←/→ move a year, PageUp/PageDown ten, Home/End to either end.
- **Click a province** to see who held it over the whole period. **Click a clan** in the roster for its story, key people, alliances and battles. **Click a red cross-stitch** on the map for a battle or turning point. Esc closes the story.
- **Reading the cloth:**
  - Solid dye: one power held the province.
  - Diagonal stripes: it was split between two powers.
  - Undyed, flecked cotton: many small lords held it.
  - Cream running stitches: alliances.
  - Red cross-stitches: battles.

## How it's built

| File | What it does |
|---|---|
| `index.html` | Layout and all styles (the indigo, the dyes' surroundings, the band) |
| `app.js` | Draws the map, soaks the dyes in, the roster and stories, the band, playback |
| `model.js` | Pure functions: the map for each year, province counts, era names (`node test.js` tests them) |
| `data/history.js` | The history, written for this app: 43 clans, the 1467 starting map, 322 changes of hands with notes, 36 battles and turning points, 12 alliances |
| `data/provinces.js` | Province shapes, generated by `tools/build_provinces.py`; don't edit by hand |
| `data/images.js`, `images/` | One picture per battle and clan (59), from Wikimedia Commons, public domain or Creative Commons only; made by `tools/fetch_images.py` then `tools/shrink_images.py` |
| `main.py`, `build.bat` | The exe: pywebview window, built with PyInstaller |
| `tools/` | Province extraction, font subsetting, icon, screenshots |

**Checked against Wikipedia on 2026-11-07** (`tools/wiki_check.py` fetches the summaries of every battle, clan and person). That check fixed the following; where English Wikipedia and Japanese histories disagree, the app says so instead of picking a side.
- Seven birth and death years.
- Nobunaga's age at Okehazama.
- How Tedorigawa was fought.
- How long Tottori lasted.
- The Satake's and the Sō's sides in 1600.

Smaller notes were also added: the Mount Hiei excavations and the Portuguese guns at Okitanawate.

**Territory is an approximation.** Each of the 68 old provinces (令制国) shows the power that dominated it; many were shared among small lords. Years are rounded to the year of the main event. To change the history, edit `data/history.js` and run `node test.js`. The test checks:
- every province, clan and reference exists;
- the years are in order;
- each dye and stencil pair is used once.

**Changing text:** the fonts are cut down to the characters the app uses. After adding new text (especially kanji), run `python tools/subset_fonts.py <folder with the full fonts>`. The full fonts come from github.com/google/fonts (`ofl/shipporiminchob1`, `ofl/zenkakugothicnew`). Then rebuild with `build.bat`.
